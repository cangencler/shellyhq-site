Why Shelly

Less friction between people and AI

Today's models can do far more than most people ask of them. What holds people back is friction: tools to install, prompts to engineer, files to carry back and forth. We designed Shelly to take that friction away, so anyone can use AI the way power users do.

What power users do today
  • Install agents and command-line tools, then keep them working
  • Write long prompts and manage context by hand
  • Move files in and out, wire up scripts and schedules
  • Babysit long jobs and remember to check back
What anyone does with Shelly
  • Send a message in Slack, WhatsApp or Telegram
  • Say what you want in plain words. Shelly plans the steps
  • Attach the file, get the finished one back
  • Move on. Shelly reports back when the job is done

Same engine the power users run. None of the setup.

Product

A real workspace behind every chat

A regular chatbot only writes text. Shelly has a computer to work on, so a request ends with a finished result: the edited file, the report, the scheduled follow-up.

Real work, not just answers

Reads and writes files, runs commands, researches the web and picks up where it left off in the next message.

Files in, files out

Send a PDF, a photo or a spreadsheet. Get back the edited file, a report or a live web page, in the same thread.

Jobs that outlast the chat

Long downloads, scans and scripts run in the background. Shelly comes back to the conversation when they finish, or when they need you.

A private sandbox per person

Everyone gets an isolated workspace with their own files, memory and network policy. Nobody sees anyone else's conversations.

Documents, voice and media

Turns phone photos into searchable PDFs, transcribes videos and voice notes, generates images and sends documents to the printer.

Built for small teams

Channel agents with member allowlists, project channels, a Slack home tab and usage tracking. When Shelly can't do something, it logs it, and that log drives what we build next.

Reminders & calls

It remembers, and it can call you

No separate reminder app. Tell Shelly what to remind you about and when, in the same chat. When it's time it writes back, and if it really matters, it calls you.

Reminders in plain words

“Remind me about the bill tomorrow at 10.” “Ask me for the weekly report every Monday.” One-off or recurring: Shelly works out the time and tells you what it set.

A phone call when it matters beta

Say “call me” and Shelly rings you from its own number or on WhatsApp when the time comes. It reads out the reminder and answers your questions on the line.

Keeps watch for you

“Call me if this domain becomes available.” “Tell me when this page changes.” Shelly checks on a schedule and only speaks up when something happens.

How it works

Three steps, one thread

No new app to learn. The conversation is the interface, and every thread keeps its own context.

  1. 1

    Ask in chat

    Message Shelly in Slack, WhatsApp or Telegram. Attach files if you have them. Each thread is its own conversation.

  2. 2

    It works in your sandbox

    Claude Code runs inside your private workspace: reading, writing, running and checking. You see each step as it happens and can stop it at any time.

  3. 3

    Results land in the thread

    Answers, files and live pages come back to the same conversation. Long jobs report back on their own when they're done.

Security

The box draws the boundary, not the model

An agent that runs commands can only be trusted as far as the box it runs in. Shelly is designed around isolation from the start.

Isolated by default

One container per person, no host access, no shared folders, resource limits, and a default-deny network that keeps each sandbox off the local network.

Secrets stay outside

Chat tokens never enter the agent's workspace. Outgoing messages and file deliveries go through a broker that checks every request against allowlists.

Only people you approve

Shelly talks only to allowlisted people and channels. Messages from unknown numbers get no reply at all.

Your own Claude account

Each deployment runs on its owner's Claude plan or an organization API key, following Anthropic's terms. We never collect or broker anyone's Claude credentials.
